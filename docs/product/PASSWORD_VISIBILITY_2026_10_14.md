# App 密码显示切换（未发布）

UI agent设计，App实现：Cloud登录密码框右侧提供18px眼睛/斜线眼睛，32px点击区；沿用输入框圆角、浅深色主题、hover与键盘焦点样式。密码默认隐藏，点击显示，再点击隐藏。按钮可访问名称分别为“显示密码”“隐藏密码”，aria-pressed表示当前状态。

切换使用同一个输入框，保留密码值、选区和光标；鼠标不抢输入焦点，键盘操作保留按钮焦点。按钮不提交登录，实际登录仍使用原密码值。关闭并重新进入登录页后恢复隐藏，认证状态变化时也恢复隐藏。没有新增持久化密码或可见状态。

验证：App226项全量测试无跳过通过，typecheck通过；真实React renderer模拟IPC在浅/深主题、720/900窗口检查默认隐藏、显示/隐藏、鼠标与键盘焦点、选区保留、重开复位及显示状态下登录参数不变。图标实际点击区32×32且不超出输入框。截图只包含合成示例，不使用真实用户密码。

本次仅提交并推送Git，不上传网站、不打包发布；线上安装包继续为0.3.16。真实服务器登录/安装行为未变更，界面验收使用模拟IPC。
