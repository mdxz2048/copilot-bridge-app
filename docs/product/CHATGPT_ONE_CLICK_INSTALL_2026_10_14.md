# ChatGPT 一键安装（尚未发布）

用户点击一次“安装 ChatGPT”，Bridge 自动尝试 Microsoft Store 安装。商店未开始下载、失败或下载停滞时，先等待旧安装进程退出，再自动从官网取得官方离线包，校验并安装。用户无需选择下载渠道；Windows 要求管理员授权时，界面提示允许系统安装。

启动只检测，不自动开始安装。安装弹窗统一显示当前状态及实际下载进度；“稍后”仅隐藏提示，安装继续，可从主页“查看安装进度”重新打开。安装失败可重试。实际确认成功后显示“ChatGPT 安装完成”，两秒后自动收起，或点击“完成”关闭。安装成功不自动开启 Cloud，模式切换仍需确认。

## 检测规则

四个本地渠道采用 OR：任意渠道返回有效官方身份即可确认安装。商店网络或 winget 的失败不否决本地成功证据。

- Windows Appx 当前用户官方包注册且状态正常。
- 当前用户官方注册记录，同时对应清单和程序文件有效。
- WindowsApps 官方安装目录，清单身份、架构、发布者与 ChatGPT.exe 均符合要求。
- 正在运行的 ChatGPT 来自官方 WindowsApps 安装目录，且清单和程序文件有效。

目录/进程渠道检查 `OpenAI.Codex`、x64、官方发布者及官方包名称；空目录、非官方清单、缺失程序和同名进程不能算成功。安装检测独立于下载任务，每五秒及窗口重新获得焦点时刷新；重开 Bridge 会重新检测。检测失败与确定未安装区分。

## 修复原因

旧实现的 Store 观察结束或取消下载会停止安装观察；取消/旧错误可能覆盖后来完成的安装。此前 winget 查询失败会否决部分本地注册证据。首次引导与安装弹窗分别存在，关闭后重新弹出引导，形成循环。

现在检测成功会使旧安装事件失效，阻止晚到的进度/错误覆盖成功；检测到外部安装成功时会中止尚未开始系统安装的冗余离线下载，不中止 Windows 已接管的部署。应用刷新也不能用旧读取结果覆盖新安装状态。
