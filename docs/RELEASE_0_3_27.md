# 0.3.27 登录恢复与本机账号选择

开机自动恢复登录遇到断网后，原 policy 轮询只读账户，未重新完成启动 resume 验证。现在未验证的启动会继续复用合并的 refresh/resume 流程；系统 online 事件触发完整刷新并仅清除临时网络退避，后台五秒轮询仍为无事件时的恢复保障。登录失效、设备撤销与主动退出不会靠保存的密码反复登录，模型 POST 没有重放。

恢复请求按认证代次校验，手动登录/退出后的旧结果不能恢复旧账户；HTTP resume 在令牌轮换前也校验认证代次。即使离线退出远程请求失败，本机令牌仍清理。成功恢复按现有模式资格启动 Bridge，不自动切换 Cloud/原账号。

登录成功后默认保存账号与密码，可取消“在此电脑保存账号和密码”。SavedLogins 使用 Electron safeStorage / Windows 系统加密，原子落盘并序列化访问，文件位于应用 userData 的 cloud-saved-logins.enc。账号按邮箱规范化去重，最多20个，按最近成功登录排序；账号列表不含密码，按明确选择读取单个密码，支持忘记。服务 origin 隔离，不能加密时拒绝明文降级，失败不会把登录本身变成失败。密码不进入普通配置、广播或诊断。旧版只有刷新令牌，不能恢复此前没有保存的密码；需要首次手动输入并成功登录后保存。

登录页进入时填入最近保存账号，选择另一账号立即清除旧密码；异步读结果按选择代次校验，不能覆盖另一个账号或用户手输。密码默认隐藏，登录成功/关闭时清理组件状态。小窗口登录按钮固定于底部，保留套餐未开通提示、设备替换选择和键盘焦点约束。

291项测试全部通过，无跳过；构建/类型检查通过。真实 Windows safeStorage 用合成凭据写入、重开读取、忘记通过，文件不含明文。真实浏览器模拟 IPC 核对浅色1280×720、深色720×520及长邮箱切换；不等于完整Electron业务或真实断网重启电脑验收。未重启当前官方客户端，也未执行安装器。

安装包与最新55个编译文件逐字节一致。0.3.27 已通过现有管理员发布接口上传完整安装包及blockmap并发布；上传传输使用0.3.26基线+差量重建，双端完整SHA验证，发布文件仍是完整安装包。开发Windows上的现有UpdateManager通过公开HTTPS完成差量下载/SHA到READY，没有运行安装器。证据见 docs/evidence/0.3.27/。
