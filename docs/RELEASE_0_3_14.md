# 0.3.14

模型下拉菜单仅显示服务器返回的可用模型，隐藏待配置条目。模型和用户权限由 Cloud 同步，上游域名及 API Key 留在服务器。

Cloud 本次接入 GPT 中转，仅开放 GPT-6 Sol 和 DeepSeek Flash。其余实际导入的 GPT 型号默认停用，管理员验证、启用并授权后才出现在用户目录中。用户余额按已发布的费率版本结算。

验证包括 App 206 项回归、Cloud 129 项单元及 30 项隔离数据库测试、GPT 配置对话框桌面/窄屏检查、安装包 ASAR 与当前构建逐文件 hash 核对，以及真实 App 本地代理到 Cloud 的文本/流式/模型切换与工具续接。证据以实际生成的 acceptance 文件为准；未运行官方桌面 GUI 的交互场景不计为验收。
