# 0.3.23 — 有界等待与超时提示

控制接口默认时限由 30 秒改为 15 秒，并覆盖连接、响应内容读取和签名准备阶段；网络故障和读取异常显示中文反馈。模型 Responses 保留独立 70 分钟上限及已有服务端分段时限，不套用普通查询短时限。

所有公开 preload IPC 均有等待上限：普通读取 30 秒、模型列表 25 秒、账号登录/刷新 60 秒、切换/重启 90 秒、打开官方客户端 75 秒；进程检测 20 秒。系统/网络超时结束界面等待；写操作提示结果可能已生效，同一通道未结束前阻止重复发起。IPC 等待结束不冒充底层操作已取消，实际状态仍以主进程事件或重新读取为准。

更新检查 15 秒；更新和官方安装包下载建连 15 秒、连续无数据 60 秒、总时限 15 分钟，失败清理临时文件并可重试。Windows 登录凭据子进程 15 秒无结果会结束并显示安全错误；初始化失败仍打开主界面，可重试连接。操作系统安装本身保持独立时限，后台状态继续显示，不能假装取消已提升权限的 Windows 安装。

失效的刷新令牌仅拒绝一次后清理本地认证，并停止后续带旧凭据请求；临时网络故障及限流退避 10/20/40/60 秒，不删除有效凭据。账号退出、设备撤销和锁定后停止本地 Cloud 连接及模型轮询。原账号恢复路径保留。

验证：254 项测试通过，真实 React renderer 和编译后 preload 的浅色/深色超时提示、按钮恢复检查通过（模拟 IPC，缩短测试等待）。未在真实用户设备上制造断网，未执行当前宿主的安装或官方客户端重启。

本次 App 发布仅含超时与登录续期修复。闲鱼购买、手机专属提交链接和管理员订单审核仍为单独设计原型，没有虚构线上已提供购买提交服务；本次未改 Cloud 业务源码或数据库。
