整窗以参考图为依据：柔和中性背景、清晰正文/次要文本字号、整齐边距和留白、简洁套餐信息条、带图标的AI服务卡片、底部就绪状态与详情入口。卡片/按钮/分隔层级保持一致，避免多重重边框或不同圆角杂糅。视觉改版不创建聊天窗口、模拟会话或展示不存在的能力。

| 区域 | 设计与交互约束 |

## Handler与业务不变量

本期不修改业务handler、Cloud连接、模型计费、设备版本/latest-only、安装/UAC策略、profile切换与重启调用。继续沿用现有真实状态和操作：升级检查/下载进度/READY安装、设置、Bridge开关、官方安装/下载并安装、账户与查看详情。视觉可重排入口和改善文案，但不能虚构自动切换、免重启生效、会话永久共享或Word/Agent完整支持。

顶栏升级图标可展示检查/下载/READY/错误状态，保留主动安装决定；不新增自动强制弹窗。caption区域使用原生窗口行为，升级/设置不能抢占最小化/最大化/关闭点击或drag区域。
