# 0.3.30

Public release notes: **UI更新**

Implements the approved UED light/dark appearance in the existing App: vertical dashboard, compact balance summary, paired model/reasoning controls, settings navigation and shared dialogs. Update/settings toolbar controls share sizing; update checking, byte-based progress, ready and error states retain the existing UpdateManager lifecycle and explicit installation confirmation. Recharge/account text actions retain transparent hover/pressed surfaces. Default remember-password behavior remains enabled and can be cancelled.

Compatibility: the live API minimum before release is 0.3.28; this UI release does not change the protocol, login, billing, device proof or server services. The minimum remains 0.3.28, and a newer recommended version does not force compatible existing clients to stop. The deployed gate is checked separately for 0.3.27 (reject), 0.3.28, 0.3.29 and 0.3.30 (allow).

Validation: 298 App tests pass, including the TypeScript/Vite/main build. Real browser visual/interaction review includes both themes, compact windows, high DPI, long values, account lock/zero balance, update states and text-action hover/pressed/focus. Packaged renderer/main files are compared byte-for-byte with the build before upload. Public download/UpdateManager evidence is recorded under `docs/evidence/0.3.30/` after publication.

The local installed UI preview was version 0.3.29; publishing 0.3.30 does not silently install it or restart the official client. No website UI or API deployment is included in this App release. Real production payment, official-client restart and full model-generation flows were not rerun for this presentation-only change.
