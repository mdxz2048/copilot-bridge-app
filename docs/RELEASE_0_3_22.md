# 0.3.22

修复 Cloud 账号已认证但本地转发失败或停止后，模型选择消失、打开 ChatGPT 被禁用的情况。已有平台策略同步和主动刷新会恢复已启用的 Cloud 本地连接；失败状态明确显示“本地连接未就绪”并提供重试。重连合并并发启动，失败自动重试间隔至少 15 秒，仅在账号、服务和 Cloud 模式可用时恢复。

“待生效”改为“需重启 ChatGPT”，表示本地连接配置等待官方客户端读取，与账号余额无关。经本地密钥认证的模型/Responses 流量到达后，可自动确认 Bridge 配置已被使用；健康检查、未认证请求和切回原账号的待重启状态不能清除此提示。配置变更与确认串行，避免互相覆盖。

验证：App 244 项测试通过，浅色和深色真实 React renderer 检查重试、模型菜单和打开按钮。生产只读排查确认受影响账号状态有效、余额大于零且有模型授权；未修改账号权限。截图所对应设备的确切本地失败原因未获取，不据此推断端口冲突。未在该用户设备运行验证，未重启当前开发宿主的官方客户端。
