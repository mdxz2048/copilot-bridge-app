# 主界面 UI 验证（2026-10-19）

主界面保留 Apple 浅灰白蓝风格，改为模式、账户、当前服务三层布局。900×700 使用舒展间距，720×520 使用紧凑间距；账户身份与登录状态成组，充值靠近余额，账户入口独立置右。Cloud 的模型与思考控件并排；说明与主按钮同行。长错误在主页摘要显示，完整内容与请求 ID 放入复用的 CompactDialog，保留焦点约束、Escape 和返回触发按钮。

## 验证结果

- `node --test test/renderer-flows.test.mjs`：50/50 通过。
- `node node_modules/typescript/bin/tsc -p tsconfig.renderer.json`：通过。
- `node test/main-layout-capture.mjs`：真实 Electron renderer，载入实际 App，仅 IPC 返回合成数据，不启动或关闭官方客户端。
- 900×700、720×520 × 浅色/深色 × OFF、Cloud、长错误、锁定、余额不足、维护横幅、未登录、长套餐与金额 × 100%/125%/150%/200%：128 个布局检查通过。
- 每档缩放额外 8 个检查：充值 hover 对比度和完整错误详情、请求 ID、关闭与焦点恢复，共 32 个交互检查通过。另保存 focus 与 disabled 状态截图。
- 检查实际内容 `clientHeight == scrollHeight`、主容器不溢出以及按钮、金额、状态元素边界，未通过隐藏滚动条裁切控件来达成结果。
- 充值 hover 字色采用深蓝、浅蓝背景，深色模式采用亮蓝；最终各档实测对比度最低 5.81:1。

## 可复现方法

使用支持当前仓库的 Node 运行：

```powershell
node --test test/renderer-flows.test.mjs
node test/main-layout-capture.mjs
```

运行时截图和完整 JSON 默认输出到 `work/ui-main-layout/captures-{1,1.25,1.5,2}/`。该目录包含临时 bundle，不应提交；本轮原始捕获已归档到聊天的临时工作目录，摘要保存在 `docs/evidence/20261019-differential/ui-summary.json`。测试入口、Electron 捕获脚本和合成 fixture 位于 `test/main-layout-capture.mjs`、`test/main-layout-electron.cjs`、`test/fixtures/main-layout-renderer.tsx`。

如只重拍新版本号的关键预览：

```powershell
$env:UI_CAPTURE_SCALES='1'
$env:UI_CAPTURE_SCENARIOS='cloud,error'
$env:UI_CAPTURE_DIR='work/ui-main-layout-preview'
node test/main-layout-capture.mjs
```

主验证完成后，fixture 改为读取 package.json 的版本，再重捕 8 个关键布局和 8 个交互，全部通过。未改变生产源或验证规则。

## 证据边界

- 高 DPI 的 Windows/Electron 原生窗口 content size 会舍入：100%/125% 实际为请求 DIP 尺寸；150% 实际为 902×702 和 722×522；200% 实际为 901×701 和 721×521。JSON 记录实际 viewport，不将其宣称为每档精确 720×520。
- 隐藏窗口的 synthetic mouseMove 在高 DPI 下命中不稳定；hover 截图通过 CDP `CSS.forcePseudoState` 触发真实 renderer 的 CSS 规则，并确认元素匹配 `:hover`。不把该项称为真实用户鼠标端到端测试。
- fixture 的 BrowserWindow 没有产品原生标题栏叠层，所以截图不含最小化/最大化/关闭原生窗控。生产 App 的 native overlay 配置没有由 UI 修改，工具顺序与标题栏组件保留。
- 布局测试不能证明真实 Electron 配置切换、官方客户端重启、生产登录、安装或升级完成；这些由其他测试/验收独立处理。
- 账户、金额、错误、邮箱全部为合成数据，未访问真实账户或私人资料。
