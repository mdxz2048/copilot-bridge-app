# 账户充值入口（2026-10-16）

账号已登录时在账户概览中新增“充值”按钮，与在线设备、邀请好友同一操作行。点击进入原账户弹窗内的联系页，显示用户提供的管理员微信二维码、注册邮箱和充值说明，可返回账户。管理员按现有流程增加余额，原有轮询自动同步。

二维码原图存放于 public/admin-wechat.png，由 Vite 复制到 dist-renderer；保持原图字节，不接入在线支付、不自动联系管理员。

验证：App typecheck、build 及 233 项测试通过；真实 React renderer 搭配模拟 IPC 在 720×700、720×520（125% DPI）、浅/深色下验证入口、二维码加载、返回、弹窗边界和账户概览无溢出。小窗口联系页内容可滚动。二维码与构建输出 hash 一致。没有运行完整 Electron、扫描微信添加管理员或执行真实充值。

本功能已随0.3.19发布，公开最新/最低版本均0.3.19，详见docs/RELEASE_0_3_19.md。早期界面验收证据：docs/evidence/topup-registration-20261016.json。
