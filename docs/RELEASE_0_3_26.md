# App 0.3.26 — 一屏主界面与差量升级

2026-10-19。Windows 安装包与 Cloud 差量下载支持已发布；不自动安装到当前开发宿主。

## 用户变化

- 保留浅灰白、柔蓝、圆角风格，主页整理为模式、账户、当前服务三层。默认 900×700、最小 720×520；模型与思考并排，说明与主按钮同行。
- 套餐与登录状态成组；用量、余额和充值分组；账户入口独立。修复充值 hover 蓝底蓝字，并覆盖浅深色、焦点、按下和禁用状态。
- 长错误只在主页显示摘要，完整内容和请求 ID 可打开详情；错误、维护、待重启状态避免向下堆叠。底栏健康状态同时要求服务可用且无错误。
- 更新优先复用当前版本安装器的相同压缩块，只请求差异字节。范围响应、完整重建 SHA-256 或格式不符时自动转完整下载；READY 和安装前继续校验。
- 本版是首次支持差量的版本。0.3.25 等旧版更新器仍需完整下载一次 0.3.26；从本版起可享受后续差量。手动安装利用 NSIS 原生 installer.exe 缓存，经当前版本元数据及完整 SHA 验证后使用。缓存清理、缺索引或低复用率时走完整下载。

## 差量与缓存边界

无需新依赖或更换 Electron/NSIS。索引使用 electron-builder gzip v2、单 file、最多 100000 块、压缩最多 2 MiB/解压最多 16 MiB；安装包最多 512 MiB。HTTPS 同源、拒绝重定向，严格校验 206、强 ETag、Content-Range、长度和内容编码。整个下载有连接/空闲/总时限。

独立 NSIS 缓存只读，不复制或修改。App 更新目录最多保留当前版本和待安装版本的安装器及小型索引/元数据，清理遗留 part。损坏本地元数据重新查询平台，锁定的候选基准不阻止尝试其他缓存。

Cloud 提供 by-version、blockmap 管理上传/公开读取、Range/If-Range。已发布旧包只允许首次补索引，之后不可覆盖；发布并发使用真实数据库行锁。保留最近三个稳定版本用于无本地元数据时的 bootstrap，超窗可完整回退。无需数据库迁移。
