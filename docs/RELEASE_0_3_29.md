# 0.3.29 订单审核通知

提交订单后，服务端向 zhipeng2048@gmail.com 发送待审核邮件。管理员点击链接登录后台核对付款并审核，链接自身没有审批权限，不会自动通过。审核后发送管理员回执与用户结果邮件，失败时由服务端重试。

已登录 App 增加待确认的订单审核结果提示，显示订单号、通过后的到账金额或拒绝说明，并重新同步服务端余额。启动、恢复联网及回到窗口时读取通知，前台每 30 秒查询一次；隐藏时暂停。明确点击“知道了”并收到服务端确认后才消除通知；离线期间的通知保留，重新登录后仍可查看。通知按账号和订单提交次数隔离。历史已审核订单在迁移时标记已读，避免集中打扰用户。

本次最低兼容客户端保持 **0.3.28**。服务端已将最低版本与最新版分离；发布 29 不会仅因版本不同拒绝 28 的请求。28 可继续使用已有功能，新通知组件需升级 29。后台检查和下载更新，右上角提示；用户点击“安装更新”才退出 Bridge 并启动安装器，重启 App 不会自动安装。
