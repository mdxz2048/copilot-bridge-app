# 0.3.13 GPT 模型配置与自动同步

Cloud 模型列表由服务端提供，包括 READY、SETUP_REQUIRED、UNAVAILABLE 状态。待开通 GPT 可选择，界面明确提示管理员配置、充值及启用；请求前检查最新目录，待开通模型不会发起生成，撤销权限后不继续使用旧目录。

每 5 秒同步账户、余额、用量、设备和模型目录；慢请求去重，暂时离线后重试，不自动更换用户选中的模型，不影响原账号配置。锁定/解锁同步保留，模型或权限改变后用户选择模型并新建会话。钱包交易明细仍在完整账户刷新时读取。

这次升级补齐同步逻辑；以后新增模型、修改权限或调整余额，只需要后台操作，不需要为数据变化发布客户端。

OpenAI 连接由服务器管理，客户端不保存 API Key。预置 API 模型 ID 和能力依据官方文档，待开通能力不代表真实生成已验证。本次无付费生成，也没有重新启动当前官方客户端。
