# App 0.3.25 — 充值入口与中文故障原因

2026-10-19。开发、回归、生产 API 更新、Windows App 发布与公开下载验证已完成。

## 用户变化

- 主界面账户摘要右侧显示「已登录 · 充值　账户 ›」。充值为独立蓝色文字入口，直接打开原购买审核流程；账户弹窗内旧充值入口已移除。未登录隐藏，零余额仍可用，窄窗换行，深浅色和键盘焦点已验收。
- 余额不足返回 HTTP 402 / INSUFFICIENT_POINTS，并提示「余额不足，请打开 Copilot Bridge，点击『充值』，到账后重试。」不将拒绝请求伪装成模型的成功回答。
- 流式工具参数异常、上游失败、超时、网络断开、输出长度限制等原因以中文返回。工具参数失败包含工具名称，平台反馈保留调用 ID、参数异常类型和上游片段，并脱敏、限长、加密上传。
- 仅对已声明的 functions.exec / python.exec 代码包装兼容唯一、非空的 code 字符串。普通函数工具的 code 字段保持原样；空对象、冲突字段和损坏 JSON 明确失败，不猜测或执行代码。
- 突然 EOF 补发 response.failed，保持响应 ID、事件序号与失败原因；不伪造 response.completed，不自动重新执行整轮任务。完成事件在输出校验通过后才转发。
- 官方 Codex 对 response.incomplete 忽略 error.message，因此 Desktop 出口将未完成终止适配为带中文 error 的 response.failed；平台诊断和服务端计费仍保留原始 incomplete 事件、原因及状态。
- 邀请复制文案删除旧“联系管理员增加余额”说明，明确首次购买充值经管理员审核到账后才发奖励。

## 验收范围

- App 全量 266 项自动化通过，覆盖协议/失败反馈、账户 UI、充值隔离弹窗与登录状态；API typecheck/build 与相关 8 项单测通过。
- 上一轮 99 次真实 DeepSeek 录制响应在新转换器全部回放通过。这是离线回放，不是新增 99 次真实调用。
- 本机官方 Codex CLI v0.163.0-alpha.10.2 接入注入合成错误的隔离 Bridge，余额不足、工具空参数提示、突然断流、输出超限四类错误均显示中文具体原因，每例仅一次模型入口调用。CLI 仍附带自己的英文错误前缀。
- UI 真实 React renderer 合成 IPC，900/620px、深浅色、长邮箱、未登录状态与关闭焦点恢复通过。
- 没有关闭当前官方宿主，没有在正式 ChatGPT/Codex GUI 发起这些失败任务，没有自动安装到开发宿主。也不把正常的本地工具非零退出全部当成平台故障；工具由官方客户端执行，Bridge 只能诊断它实际收到的调用、结果和协议错误。
