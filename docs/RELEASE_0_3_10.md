# 0.3.10 使用限制改为提示与管理员锁定

Cloud 模型使用取消余额、历史计费异常、周期用量和并发拦截。正常可靠用量仍记账；余额不足保留待结算记录，未知用量保留待核对记录，两者不阻断新会话。账号风险由管理员主动锁定/解锁，App 明确显示锁定状态。零余额提示仍可使用，客户端断开不再误标成普通超时。

后台用户管理收敛为正常/锁定、余额增减、套餐、模型多选、在线设备与每用户最大设备数；其他记录折叠。管理员余额调整即时生效，无需审批，保留审计和幂等。

修复开关状态竞态：晚到的切换前状态刷新不能覆盖已确认的 ON/OFF；重复安装检测不再触发全量刷新，重启中禁止再次切换。临时配置验证保留原账号、会话与工作区；实际官方客户端重启尚未在当前宿主执行。

App 195 项测试通过，Cloud 单元 119 项、独立 PostgreSQL 22 项、Web 15 项通过。真实组件浏览器验证锁定/解锁、余额增减、设备上限与移动宽度。包内 43 个编译文件与当前 dist 一致。没有自动安装到正在运行的宿主，也没有重跑用户原始网页任务；浏览器验证使用合成数据。
