# 消费记录 — 0.3.32 本地预览

按已确认的设备优先设计实现三层页面：设备总览 → 设备逐笔消费 → 消费明细。支持今天/近 7 天、分页、设备改名、本机标识、折叠计费依据、读取失败重试与深色主题。充值、奖励及管理员调整留在单独的「余额记录」入口。

通过只读 IPC 调用设备签名的本地 Cloud 消费接口，金额全部来自服务端。待归集不代表待扣款；未知金额不显示为零。只有汇总的历史数据不补造逐笔模型和用量。费用分项只在保存费率能准确解释实际扣款时展示，其他记录展示真实总额和可核对的说明。

App 版本 0.3.32；域协议新增读取为 2.11.0，现有桌面握手和最低兼容版本不变。现有正式版安装和官方 ChatGPT/Codex 配置不作改动。

本机 API http://127.0.0.1:3311，后台 http://127.0.0.1:3310/admin。预览产品仍为 Copilot Bridge Preview，独立应用 ID、独立用户目录和 loopback Cloud。所有本地演示消费由合成数据产生，不连接付费模型。本轮不上传、不部署远端、不推送 Git。

验证：App 301 测试通过，服务端 210 单元测试、10 个独立本地 PostgreSQL 测试、10 协议测试通过。最终安装包和实际 Electron 验收结果见 evidence 下的消费记录验收文件。
