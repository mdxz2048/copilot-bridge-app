# 扣费记录与意见反馈（本地候选）

2026-10-29 初始在 0.3.30 上增量实现；后续按用户要求已打包并本地安装独立的 0.3.31 预览版，详见 [本地预览安装记录](LOCAL_PREVIEW_0_3_31.md)。未上传、未发布远端版本、未推送 Git。下方保留初始候选验收范围。

“我的账户”新增扣费记录与意见反馈。账单调用现有 Cloud `/api/v1/me/bills`，按设备上线区间汇总，20 条分页；支持消费扣费、全部、余额增加，明确待结算区间与已扣余额的关系。没有改变代理、模型请求、计费、登录、模式切换或官方客户端管理逻辑。

反馈支持类型、标题和正文，以及我的反馈/处理状态。失败保留草稿与同一提交编号，成功后显示短编号与查看入口。主进程校验载荷，沿用 Cloud 设备鉴权；renderer 不接触 token，不自动上传聊天、文档或诊断信息。Cloud 新增的反馈 API 与数据库迁移需要先部署，旧服务器不会伪装成功，错误在表单中可见。

UI agent 先制作设计稿并审阅真实 React 渲染。沿用现有 CompactDialog、深浅 tokens、焦点管理和内部滚动；720×520 下可滚动到表单提交。完整设计稿在当前任务 `work/ui-account-admin-20261029/index.html`。

验证：全量 300 项测试通过，无跳过，包含新增签名账户接口/未登录不发请求测试。构建和类型检查通过。浏览器模拟 IPC 验证消费分页、筛选、读取失败重试、反馈失败保留正文和同编号重试、提交成功与我的反馈；900×700/720×520 深浅主题截图通过。Cloud 独立 PostgreSQL 35 项、Web 19 项、contract 10 项通过。
