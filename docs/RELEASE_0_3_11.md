# 0.3.11 工具兼容与会话恢复

DeepSeek 的工具别名只有唯一匹配已声明工具时才能恢复名称、命名空间和 custom 输入。兼容裸名称及供应商重复命名空间拼写，未知或歧义名称返回明确协议错误，JSON/SSE 使用相同规则。保存上游历史时统一为声明的别名，避免下一轮重放不匹配。OpenAI 原生路径保持现有行为，本版不做真实 OpenAI 验收。

未收到工具结果时不再返回空的 completed。部分工具结果保持关联并返回 TOOL_RESULTS_PENDING，其他结果到达后继续。新的用户指令恢复当前任务：缺失结果明确标记 interrupted，告知模型不能假设执行成功，可按需要重试；不影响独立会话。字符串增量指令保留已有历史。

DeepSeek agent_message 以外部消息信封转换为 user/input_text，保留作者、接收者、正文及其他字段；增量工具续接同时保留这些消息。Bridge 不执行工具，也不创建 Agent Loop。

工具名称/类型、匹配结果、等待数量和恢复原因记录结构化脱敏诊断；不记录工具参数、结果或私有文档正文。界面明确显示 Cloud 实际模型，提示切换后新建会话。

验证：App 全套测试、Cloud API 单元测试、类型检查与构建；JSON/SSE 工具恢复、歧义拒绝、重复继续、独立会话、子任务信封、跨会话拒绝。生产部署与安装包验证见交付记录。模拟测试不是官方客户端任务的真实验收；不自动重启当前开发宿主。
